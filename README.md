# 飯ガチャ 🎰🍝

予算もメニューもガチャで決まる、外食注文シミュレーター。レバーを回すと予算（¥1,000〜¥5,000）がランダムに抽選され、その予算内でお店のメニューが自動で組み合わされます。何が出るかはカプセルを開けてのお楽しみ。

🎮 **遊ぶ**: <https://0x5da3.github.io/meshi-gacha/>

> ⚠ 本プロジェクトは個人制作のファンプロジェクトです。株式会社サイゼリヤ・株式会社壱番屋・株式会社王将フードサービスおよび各運営会社とは一切関係ありません。メニュー・価格は各社グランドメニューを基にした参考データであり、店舗・時期により実際と異なる場合があります。

## 特徴

- **3 店舗対応** — 🍝 サイゼリヤ / 🍛 ココイチ / 🥟 餃子の王将 をワンタップで切り替え。筐体カラーも店舗ごとに変化
- **予算ガチャ** — ¥1,000〜¥5,000 から抽選。高額予算ほど指数的に出にくい設定
- **予算モード切替** — ノーマル（¥500 刻み） / リッチ（¥1000 刻み）。リッチは荒い刻みで一発逆転狙い
- **レア度演出** — 予算の大きさでレア度が決定（ポケカ風：C → U → R → RR → SR）。カプセル排出＆開封アニメーション付き
- **パチンコ風 液晶モニタ** — レバーを回すと筐体上部のモニタにリーチ→スーパーリーチ→激アツ→大当たりの昇格演出が流れる（店舗ごとにストーリー差分あり）
- **チャンスモード（ST 突入）** — レアを引くと一定回数の確変ラッシュに突入し、継続率に応じて連チャン
- **価格加重ピック** — 予算をしっかり使い切るよう、高価なメニューが選ばれやすいロジック（最大 10 品）
- **10 連ガチャ** — ガチャを回すとエネルギーが溜まり、フルチャージで 10 連が発動
- **サウンド設定** — ミュート切替＆音量スライダー（設定は `localStorage` に保存）
- **アルコール ON/OFF** — お酒メニューを抽選対象から外す切り替え
- **未開封ロック** — 指定レア度（R↑ / RR↑ / SR）以上が出たら、開封するまで次を回せないモード
- **注文履歴・排出率表示** — これまでの結果と各レア度の出現確率を確認可能

## 使い方

ブラウザで <https://0x5da3.github.io/meshi-gacha/> を開けばすぐに遊べます。

ローカルで動かす場合もビルド不要・依存パッケージなし。`index.html` をブラウザで開くだけです。

```sh
git clone https://github.com/0x5da3/meshi-gacha.git
cd meshi-gacha
open index.html        # もしくはブラウザにドラッグ＆ドロップ
```

GitHub Pages などの静的ホスティングにそのまま配置することもできます。

## 構成

すべて `index.html` 1 ファイルに同梱（HTML / CSS / JavaScript）。外部依存は Google Fonts のみで、ビルドツールやフレームワークは使用していません。

- メニューデータは `STORES` オブジェクトで定義（`[名前, 価格, カテゴリ, アイコン, メイン?, デザート?, ドリンク/アルコール]`）
- 予算抽選ロジック: `rollBudget()` / レア度判定: `budgetRarity()` / メニュー組み合わせ: `computeResult()`
